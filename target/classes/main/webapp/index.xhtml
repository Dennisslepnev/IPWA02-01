Like Hero To Zero

Nachhaltigkeitsprojekt

Öffentliche CO₂-Emissionsdaten weltweit transparent bereitstellen

Like Hero To Zero stellt öffentlich zugängliche CO₂-Emissionsdaten verschiedener Länder bereit. Registrierte Wissenschaftler:innen können neue Daten ergänzen, während Herausgeber:innen offene Einträge prüfen und freigeben.

Öffentliche Suche

Bürger:innen können den aktuellsten freigegebenen CO₂-Ausstoß eines Landes ohne Anmeldung abrufen.

Daten erfassen

Registrierte Wissenschaftler:innen können neue Emissionsdaten über eine geschützte Eingabemaske hinterlegen.

Daten freigeben

Benutzer:innen mit der Rolle EDITOR können offene Datensätze freigeben oder ablehnen.
